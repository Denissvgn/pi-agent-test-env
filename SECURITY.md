# Security policy

## Supported versions

The latest release is supported with security updates.

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Denissvgn/pi-agent-test-env/security/advisories/new).
Do not include credentials, keys, or other secrets in a public report.

For the tool's security boundaries and limitations, see the
[security model](skill/references/SECURITY.md).
