Released host registry records are now archived, so a host can run indefinitely without reaching the 8,192-record limit. `registry-compact [--dry-run]` selects released container, network and builder records that no pending, quarantined, application-helper or owner-proof record needs, appends each as one JSON line with `archived_at` to the owner-only `released-archive.jsonl` in the registry directory, syncs it and only then removes the record files; it prints the counts before and after as JSON. An interrupted compaction is completed by the next one without a duplicate line. A normal close compacts automatically once more than half of the limit is in use. `doctor` (check `host-registry`) and `registry-inspect` warn with `registry-nearly-full` from 75% of the limit, and the `host-registry-capacity` remedy now names `registry-compact`. Admission never reads the archive. Clients released before this change refuse a registry directory that contains the archive and dispatch nothing; keep them quiesced on a shared lease.
