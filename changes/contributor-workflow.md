Contributor documentation now describes one review and merge path for every
change: one task, branch and pull request; an independent review of record; and
a merge only after the required checks and the read-only review gate pass on the
exact head. Pull requests add a changelog fragment instead of editing the
changelog, and the package manifest is regenerated only when a release is
prepared. The indexed campaign documentation gives the cell, launch and registry
record counts for one or two selected Pi releases.
