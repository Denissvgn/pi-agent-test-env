`pi_lab.py init-plan --project DIR (--task TEXT | --task-file FILE)` writes a validated plan for a project. It picks the project kind (Python, Node.js, Go, Rust or generic), uses that kind's default check when one is safe to assume and otherwise requires `--check`, splits `--check` into arguments without a shell and refuses shell operators, protects `tests/`, `test/`, `spec/`, the task file and every `--protect` path, adds the Python template's implementer and (unless `--no-reviewer`) read-only reviewer, and refuses to overwrite an existing file. See `references/PROJECTS.md`.
